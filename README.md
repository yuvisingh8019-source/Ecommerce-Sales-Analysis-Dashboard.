# 📊 Ecommerce Sales Analysis Dashboard | Excel

## 📌 Project Overview

This project presents an interactive Ecommerce Sales Analysis Dashboard developed using Microsoft Excel. The dashboard provides insights into sales performance, profitability, product categories, regional sales, and customer segments.

The goal of this project is to analyze ecommerce data and present key business metrics through interactive visualizations, charts, and filters.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers
- Data Visualization
- Interactive Dashboard Design

## 📈 Key Performance Indicators (KPIs)

The dashboard tracks the following key metrics:

- **Total Sales:** $429,653.15
- **Total Profit:** $60,298.68
- **Total Quantity Sold:** 6,744
- **Total Orders:** 1,783
- **Profit Margin:** 14.03%

## 📊 Dashboard Features

### 1. Sales and Profit Analysis
Analyzes monthly sales and profit performance to identify trends and changes throughout the year.

### 2. Category-Wise Profit
Compares profitability across three major product categories:
- Technology
- Office Supplies
- Furniture

### 3. Category-Wise Sales Share
Displays the percentage contribution of each product category to total sales.

### 4. Sales by State
Uses a geographical map to visualize sales distribution across different states in the United States.

### 5. Top 10 Subcategories
Highlights product subcategories based on their sales performance.

### 6. Interactive Filters
Allows users to filter dashboard results by:
- Year
- Region
- Customer Segment

### 7. Year-over-Year (YoY) Growth
Displays year-over-year growth indicators for sales, profit, quantity, orders, and profit margin.

Based on the dashboard:

- Total sales reached approximately $429.65K.
- Total profit was approximately $60.30K.
- The overall profit margin was 14.03%.
- Technology generated the highest category-wise profit.
- Office Supplies contributed the largest share of category-wise sales.
- Phones were the leading subcategory in the displayed Top 10 Subcategories chart.
- The dashboard provides year, region, and customer segment filters for interactive analysis.
